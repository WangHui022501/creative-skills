# Storybook Shop Designer｜绘本店铺设定师

## 创作目标
把一间绘本中的小店转化为「有故事、有识别度、能真正走进去」的空间。必须同时保证**原始立面忠实度、空间逻辑一致性、清爽细腻的手绘画风、商品体系和双版交付**。本 Skill **独立于 `city-wander-notes`，默认不绑定、调用或生成其固定女孩与小狗**；两者仅可在用户希望时串联使用。

## 输入模式
- **A 文字原创**：用户只提供一句店铺主题、见闻、商品或感受时，先从零设计并绘制一张完整的原始店铺街景插画；立面应有可辨识、可推导的入口、门窗、招牌、屋顶、雨棚和展示。固定这张原始插画，再进入空间深化。
- **B 已有插画**：用户上传店铺插画时，原图为第一视觉母版。优先保留招牌、屋顶、遮阳棚、外墙配色、门窗、店外陈列和周围环境。不要在轴测中重新设计店铺。
- 用户仅要求原始插画时，在完成阶段0后停止，不擅自展开完整店铺设定；需要完整设定时进入其余阶段。
- 如果用户提供尺寸、结构或设计改动要求，以明确要求为准。无尺寸时可用合理的**概念尺寸**，不得冒充实测尺寸。

## 画风（默认：清爽细腻的绘本设定图风格）
以用户最近提供的香蕉专卖店设定图为**画风参考**，强调比旧版更少的颗粒感和更流畅的线条，但不改成纯矢量平涂。

- **线条**：深棕色或暖灰棕色手绘线稿，圆润、连贯、平滑且稳定；允许非常轻微的线宽变化与手绘自然感，避免边缘毛躁、抖动、断裂及机械僵硬。
- **填色**：更清爽、干净、均匀、清透。仅保留低强度的细腻纸张和彩铅质感，以及轻微水彩叠色；避免旧纸做旧、强噪点、砂纸式粗颗粒、厚重脏灰。
- **整体气质**：温暖、明亮、亲切、精致、有童趣又易于阅读；建筑、室内、轴测、平面与商品小插画必须使用同一套视觉语言。
- **造型**：绘本式柔和圆角与合理的建筑空间关系并存。比例可适度童趣化，但不允许空间逻辑与角色肢体畸形。
- **禁用风格**：过重纹理、粗糙做旧、纯光滑矢量平涂、3D真实渲染、塑料高光、过分商业化高饱和配色。
- **色彩**：延续店铺原画的主色调，辅色根据具体品牌与场景灵活搭配，而非机械套用香蕉店的黄色。

## 角色使用规则（默认不绑定角色）

- **Storybook Shop Designer 是店铺驱动、空间设计驱动的 Skill，不依赖固定人物或小狗。** 原创店铺插画、正立面、平面、轴测、室内氛围、商品展示都可以独立完成。
- 用户未明确提出角色需求时，不自动加入 City Wander Notes 的女孩、小狗，不读取或要求其形象档案，也不让它们出现在店铺设计图中。
- 店铺可以根据经营需求出现**原创店员、普通顾客或路人**，但这些是场景配角，不是固定 IP 角色；也可以无人，优先保持空间展示清晰。
- **只有用户明确要求使用 City Wander Notes 固定角色时**，才读取 `../city-wander-notes/assets/character-reference.png`，按图片忠实绘制女孩和小狗，并将其作为可选陪衬而非店铺主体。如果参考图片缺失，说明无法核对，不能声称精准复刻。
- 从 City Wander Notes 转入本 Skill 时，默认只继承用户选中的**店铺建筑与街景设计**，不自动继承女孩和小狗。用户明确要求沿用角色时例外。

## 核心依赖关系（不可颠倒）
**原始插画 → 锁定正立面 → 推导唯一平面 → 冻结空间事实表 → 完整外观轴测 → 室内剖切轴测 → 同空间氛围视角 → 商品展示 → 同素材双版排版**。

任何后续视图发现冲突，应回到正立面和平面修复；不允许每张图独立构思或靠文字解释矛盾。

## 阶段0：原创店铺插画（文字模式）
1. 提取经营类别、代表商品、城市环境、情绪、时间、建筑特色与用户强调的观察。
2. 构思品牌外形：独特但可经营的小店、清晰入口、门窗、雨棚或遮阳棚、招牌、室外陈列和与之匹配的邻店街道。
3. 绘制一幅完整的颗粒手绘街景。店铺与街道为主体，邻店正常营业，店员、顾客及路人可按场景需要自然出现；不得默认加入 City Wander Notes 固定角色；故事感不能掩盖建筑结构。
4. 记录门洞、墙体、屋顶、招牌、店面宽高比例、开窗、主要外部陈列等视觉事实。此图就是之后的固定外观母版。

## 阶段1：正立面锁定
- 从原始图逐一提取：店铺外轮廓和宽高比例、门窗位置、入口、屋顶形态、上部招牌、雨棚、侧招牌、材料和前场货品。
- 明确哪部分是建筑实体、哪部分是装饰道具；允许原始绘本中的夸张造型，但后续结构和功能需要能自洽解释。
- **正立面必须是平面设计依据**，不得从随机平面反推与原图不符的立面。

## 阶段2：推导平面并冻结
1. 在平面前边界准确映射正立面门、橱窗、展示与入口宽度。
2. 再确定店铺进深及侧墙、后墙和门窗。
3. 根据商业功能划分入口区、陈列区、墙面货架、中岛、收银打包区、制作区、仓储区。
4. 检查顾客动线、员工动线、货架与服务区域的相互关系；避免柜台堵住门。
5. 形成固定**空间事实表**：门位置、窗位置、货架个数及方向、中岛位置、收银区、后场、店外陈列、灯具与结构。
6. 一旦冻结，所有下游视角严格按这张平面和事实表生成。

## 阶段3：完整外观轴测
- 必须表现**整栋店铺外部轴测体量**，不是只画入口：正面、至少一面侧墙、屋顶、街道铺装与店外陈列。
- 立面正面视觉身份（招牌、雨棚、入口和屋顶）不能漂移；侧窗、建筑轮廓与平面对应。
- 背景尽量清爽，留足不被裁切的安全边距；可点缀少量植物和路人。

## 阶段4：室内剖切轴测
- 在相同建筑体量中通过剖墙/掀顶展示入口、墙面货架、中岛、收银、操作区、后场、照明与陈列。
- 所有墙洞和固定家具位置必须与平面事实表一致。
- 可使用少量原创店员或顾客表现空间尺度，也可不添加人物；默认不使用固定女孩与小狗。任何人物都不得遮挡空间关系，不新增无依据的门窗和柜台。

## 阶段5：空间氛围图
- **从平面或室内轴测中选择相机位置和视线方向**，画的是同一个空间，不是新想象的独立室内。
- 先核对前中后景实际包含的货架、柜台、门窗和吊灯，后根据店铺需要添加暖光、商品、可选的普通顾客与店员及生活细节；不自动加入固定角色。
- 对比透视图与剖切轴测，矛盾则修图而不是修改事实表。

## 阶段6：「本店售卖」
- 按店铺主题设计通常6–8款可辨识商品；独立小插画，有合理间距，保持品牌色及相同颗粒手绘风格。
- 香蕉店示例：新鲜香蕉、香蕉蛋糕、冰淇淋、奶昔、果酱、脆片、巧克力雪糕、礼盒。
- 不得无根据地把商品主题换掉。

## 阶段7：店铺说明（唯一默认版式文字）
- **成图默认仅允许一段店铺说明文字**。用户提供店铺说明时忠实采用；没有提供时可根据经营主题创作一小段自然、亲切、清晰的介绍。
- 默认将这段说明放在整张设定图左上方的独立留白中，使用与插画协调的深棕色手写感字体，可少量使用品牌色；不得覆盖图像。
- **除这段店铺说明以外，不得添加任何额外的版式文字**：包括店名大标题、英文副标题、视图名称、分区标题（正立面/平面/轴测/店内氛围/本店售卖）、设计信息、尺寸注释、图例说明、箭头标签、商品名称及编号。
- 店铺实体本身已有的招牌或包装文字属于设计对象，可以保留为画面内容；但不得把它们扩展为额外的海报标题。用户要求“完全无字”时再按要求处理这些场景内文字。
- 为避免乱码、错字和文字漂移，店铺说明应尽量作为**独立文字层**叠加在已完成的统一插画母版上。

## 阶段8：唯一插画母版
先生成且保存以下统一的视图素材，再排版：
1. 正立面
2. 整体外观轴测
3. 平面布局
4. 室内剖切轴测
5. 店内氛围
6. 本店售卖

**禁止分别生成有字版和无字版的六套图片。** 两版必须复用完全相同的像素插画或同一组原始图层，文字仅作为独立叠加层。

## 阶段9：双版交付（仅店铺说明 / 无版式文字）
- 两张**独立竖版3:4**图片，建议1800×2400或其他同等比例。纵向排列，全部图像有宽裕留白、互不遮挡、无意外裁切。
- 推荐阅读顺序：左上店铺说明与完整外观轴测、正立面、平面、室内剖切轴测、室内氛围、本店售卖商品插画。允许根据比例调整位置，但空间事实不可改变。
- **A 店铺说明版**：与纯图片版共用完整插画母版，**只增加一段店铺说明**；不得出现店铺大标题、英文名、图纸分区标题、视图标签、商品名、数字编号、箭头或额外装饰文字。
- **B 纯图片版**：复制同一套母版并隐藏唯一的店铺说明文字层；没有额外文字、分区标签、图例、装饰性外框。保留建筑自身固有的招牌、包装设计等视觉元素，除非用户另行要求完全无字。
- 两版必须**使用完全相同的图像素材、视角、构图和尺度**，仅“店铺说明”文字层开关不同。严禁分别生成两张相似但细节不一致的图。
- 输出 `shop-design-description.png` 与 `shop-design-clean.png`；可额外交付单视图素材和可编辑母版。

## 最终验收
- [ ] 未经用户明确要求，未自动添加 City Wander Notes 的女孩与小狗或读取其角色设定图
- [ ] 若有店员、顾客、路人，均作为店铺经营的自然配角，不影响空间主体
- [ ] 线条流畅、圆润、连贯，无毛躁断裂
- [ ] 纸张和彩铅颗粒仅轻微存在，无砂纸感及强噪点
- [ ] 填色干净均匀且保留少量柔和手绘层次
- [ ] 不是纯矢量平涂，也不是粗重复古做旧
- [ ] 各视图与商品插画的风格一致，画面清爽易读

- [ ] 原始图与正立面的招牌、入口、屋顶、遮阳棚一致
- [ ] 平面从正立面推导，门窗位置一致
- [ ] 外观轴测完整，外轮廓和开口与立面及平面一致
- [ ] 室内轴测家具和功能区与平面一致
- [ ] 氛围图从同一空间选择视角，未重造柜台和门窗
- [ ] 画风为非平涂的精细彩铅水彩颗粒
- [ ] 各视图有足够留白、没有遮挡或裁切
- [ ] 两版均为竖版3:4且所有插画完全一致
- [ ] A版仅有一段店铺说明，无大标题、英文副标题、分区标题、商品名称、数字和箭头注释
- [ ] B版移除店铺说明层，无其他版式文字和外框
- [ ] A、B两版的图片素材及各视图完全相同，只存在说明文字层差异

若当前工具无法保证精确的空间几何或图层复用，应明确指出这是概念图，采用先保存视图再进行图层排版的工作流，而不是声称独立生图绝对一致。
